## 总体原则（为什么是这 5 处）

OpenCut 拖拽的核心哲学（源码实锤，`opencut-classic-src/apps/web/src/timeline/`）：
1. **主场景是普通轨**（可进可出，只是永不折叠）
2. **落位 = 类型兼容 && 不重叠才进已有轨，否则新建轨**
3. **无"预览轨道"概念**——段跟手 + 落点线（getDropLineY 画在目标轨顶部）
4. **没动不提交**（didMove 判断，防空操作/undo 污染）
5. 建轨+移段 = 一次原子提交（MoveElementCommand）

## D1：主场景可入（最优先，用户今晚的痛）

**现状**（timeline.js computeDrop L243-248）：
```js
// 已有段拖到主场景（video ti=0）→ 不允许并入（主场景恒定），改在主场景上方新建叠加轨
if (!isLibrary && t.type === "video" && t.ti === 0) {
  const el = trackElOf(t);
  const r = el.getBoundingClientRect();
  const topHalf = (y < r.top + r.height / 2);
  return resolveNewDrop(topHalf ? "above" : "below", insideIdx, tracks, dragType);
}
```
**问题**：已有段拖到 main 被强制新建轨 → 用户"放不进主场景"。

**改法**：**删除整个 if 分支**。让 main（video ti=0）走正常 existing 路径（类型兼容 → 落 main）。
- 库拖入 main：同样 existing（add_to_timeline dataTi=0 → main）
- 落点重叠：走 D2 的重叠检测逻辑（同其他轨一致）

**OpenCut 参照**：`resolveTrackPlacement` preferIndex → `canUseExistingTrack`（类型兼容 && 不重叠）→ `buildExistingTrackResult` + `enforceMainTrackStart`（main 从 0 开始强制）。

**验收**：
- [ ] 拖叠加1 的段到主场景 → 段直接进 main（不弹新轨）
- [ ] 从素材库拖 MP4 到主场景 → 直接进 main
- [ ] 拖到 main 里已有段的位置 → 重叠检测（D2）→ 避让或新建轨

## D2：已有段拖动也做落点重叠检测（对齐 OpenCut canPlaceTimeSpansOnTrack）

**现状**（timeline.js computeDrop）：
- 库拖入：`trackBusyAt(t, atTimeUs)` 重叠 → resolveNewDrop（新建轨）✅
- **已有段拖动（isMove）：不检测重叠，直接 existing** ❌

**改法**：computeDrop 里 existing 分支，**isMove 时也调 trackBusyAt 检测**：
```js
if (block.includes(t.type)) {
  // 落点被占用 → 新建轨（OpenCut canPlaceTimeSpansOnTrack 语义）
  if (atTimeUs != null && trackBusyAt(t, atTimeUs, excludeSegId)) {
    const el = trackElOf(t);
    const r = el.getBoundingClientRect();
    const topHalf = (y < r.top + r.height / 2);
    return resolveNewDrop(topHalf ? "above" : "below", insideIdx, tracks, dragType);
  }
  return { kind: "existing", ... };
}
```
**注意**：`trackBusyAt` 需要支持 **excludeSegId**（被拖段自身不算占用）——改 trackBusyAt 签名加排除参数。

**OpenCut 参照**：`placement/overlap.ts` canPlaceTimeSpansOnTrack（用 excludeElementId 排除自身）。

**验收**：
- [ ] 拖段到另一段上 → 显示新建轨落点（蓝线），松手建新轨
- [ ] 拖段到自己原位置（不重叠）→ existing 正常落位
- [ ] 组移动（多选）不误判（组内成员互不排除——OpenCut 用整组 timeSpans）

## D3：删"预览轨道"弹动（用户今晚的痛）

**现状**（两处）：
1. `timeline.js renderTimeline` L476-478：`needPreview` 分支，拖动中 new 时 splice 一个 previewTrack（虚线整轨）
2. `工作台v0.8时间轴.html` dragover new 路径：`showGhostTrack(displayIndex)`（整条虚线轨）+ `showClipGhost`（影子段）

**用户要的**（OpenCut 同款）：**无整轨预览**。只有：段跟手 + 目标轨高亮 + 落点线（蓝线）。

**改法**：
1. `timeline.js`：删 needPreview/previewTrack 注入（L470-480 附近整块）；renderTimeline 里 `tr.preview` 相关分支（L505/L511）清理
2. HTML：dragover new 路径删 `showGhostTrack`/`showClipGhost` 调用，只留：
   - `showDragLine(目标轨顶部 Y)`（D4 修位置）
   - hint（"松开新建轨道"文字提示，可选保留）
   - 被拖段跟手（已有）
3. 清理：ghostTrack 元素/CSS/showGhostTrack/hideGhostTrack 函数引用全删

**效果**：拖动经过其他轨时**不再重建/躲闪**（用户说"特效1轨道会躲会闪"的根因就是预览轨 DOM 注入）。

**OpenCut 参照**：无 preview track——`view.kind === "dragging"` 时渲染层只把元素画在目标位置 + drop-line。

**验收**：
- [ ] 拖段到间隙 → 只有蓝线 + 段跟手，无整轨弹动
- [ ] 拖段经过其他轨 → 轨道不闪不躲
- [ ] 松手新建轨 → 正常建出

## D4：落点线 Y = 目标轨顶部（对齐 getDropLineY）

**现状**：`showDragLine(displayRowCenterY(displayIndex))`（轨中心）或 `showDragLine(targetY)`（existing 用轨中心）。

**OpenCut 参照**（drop-target.ts getDropLineY）：
```ts
// Y = 到目标轨为止的高度累加（含 gap），画在目标轨顶部
for (let i = 0; i < safeTrackIndex; i++) y += getTrackHeight(...) + TIMELINE_TRACK_GAP_PX;
```

**改法**：新增 `displayRowTopY(displayIndex)`（目标轨顶部 Y = 累加轨高+gap），落点线统一用它：
- existing 路径：`showDragLine(轨顶 Y)`
- new 路径：`showDragLine(新轨位置顶 Y)`

**验收**：
- [ ] 拖到任何轨 → 蓝线在该轨顶部（不是中心）
- [ ] 蓝线 X 随鼠标移动（时间位置）

## D5：没动不提交（didMove 判断）

**现状**（HTML onPointerUp）：无条件提交（relocate/move 都调）。

**改法**（onPointerUp，d.mode === "move" 分支）：
```js
const didMove =
  (d.targetKind === "new") ||                    // 建了新轨 = 算动
  (d.targetDataTi !== d.ti) ||                    // 换了轨
  Math.abs(d.curLeftUs - d.s0.start) > 10000;    // X 移了 >10ms（微秒）
if (!didMove) { /* 不提交，直接 refresh 回原位 */ return; }
```

**OpenCut 参照**（element-interaction-controller handleMouseUp）：didMove = moves.some(轨变了 || start 变了)。

**验收**：
- [ ] 点一下段不拖动 → 松手无命令、无 undo 记录
- [ ] 拖回原位松手 → 无命令
