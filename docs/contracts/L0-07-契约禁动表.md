## 自检脚本思路（可选护栏，非强制实现）

`tools/contract_guard.py`：
- 对 `draft_state.json` 做结构断言（顶层键、draft 三桶 + canvas + _track_meta、每个 seg 必含 `id` 且格式匹配）；
- 对 `mcp_server.py` 工具签名做快照 diff（首次运行生成 `contract_snapshot.json`，之后 diff，凡改动即告警）。
- 思路：用文件哈希 / ast 解析工具函数签名，`old_snapshot` 与 `new_snapshot` 对比，**只读不写回业务**。

```python
def assert_contract(state_json):
    top = ["schemaVersion","domain_version","version","materials","draft","metadata"]
    assert set(state_json) <= set(top), f"未知顶层键: {set(state_json)-set(top)}"
    d = state_json["draft"]
    assert isinstance(d.get("main"), dict) and isinstance(d.get("overlay"), list)
    assert isinstance(d.get("audio"), list) and isinstance(d.get("canvas"), dict)
    for seg in iter_all_segs(d):
        assert isinstance(seg.get("id"), str) and seg["id"], f"缺 id: {seg}"
```
