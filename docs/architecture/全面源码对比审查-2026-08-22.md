## 〇、指导原则（GPT + 用户共识）

1. **按完整剪辑器系统拆，不按已出问题的地方拆**——"你现在不知道自己不知道什么"
2. **新版 OpenCut = 行为标准，不是参考**——旧版误导 + 补丁债全部清掉
3. **我们不是 OpenCut clone**——AI Agent 层（Command/日志/MCP/可解释状态）是优势，**不能照抄删掉**
4. **补丁三分法**（不能看到补丁就删）：
   - **A 类·错误补丁** → 删（为修错误时间加的 +20帧 修正、±1ms 合并、跨通道对齐等）
   - **B 类·兼容保护** → 留（clamp、防 NaN、空数据保护——新版可能没写但工程必须有）
   - **C 类·产品增强** → 留（AI Agent 需要的 Command 日志、操作记录、事务、MCP 接口）

## 三、P0 模块详解

### ① State / Event Flow 审计（GPT：P0.5，最优先）
所有诡异问题（KF 偏移 / marker 复制 / value 被改 / 素材库消失 / 拖动弹回）表面分属各模块，**实际可能同源：事件流某一层重复触发**：
```
用户操作 → Event → State 更新 → Render → Command → Backend
```
重点查：
- pointer 事件生命周期（down→move→up 是否只走一遍）
- draft 状态是否污染正式状态
- refresh 锁 / subscribe 触发 / renderAll 触发 / command commit 顺序
- **20 帧问题高度疑似**：pointerup → commit KF → refresh → seek → 第二 channel 又取新 playhead
- 新版 OpenCut 怎么组织状态流（Editor Core / Managers / 订阅）

### ② 关键帧 KF
不只审功能，**重点审数据模型**（GPT 第三点）：
- 我们：扁平 `animations[path].keys[]`（positionX/positionY 各自 keys）
- 新版：`bindings + channels`（transform.position 是一个动画，含 x/y 分量）
- **判断**：X@3s / Y@3.666s 这种错位，根源就是"两个 channel 各自管理时间"；
  PropertyGroup（Transform → position{x,y}/scale{x,y}/rotation）模型能根治
- 行为表：播放头在 KF → ◆ 蓝；离开 → ◆ 灰；拖素材 → 自动 KF?；拖 marker → 移动/复制?；Shift 多选 → 怎么移动

### ③ 预览画布 Canvas
- 坐标系统五层：screen → viewport → canvas → element → transform
- 操作：点击选中/拖动/缩放/旋转/多选/对齐/吸附/框选
- **命中系统**（视觉看到 A 实际 hit 到 B 的雷）
- 行为表：Ctrl 滚轮/普通滚轮/中键/旋转/缩放

## 四、P1 模块详解

### ④ 时间线 Timeline
不只 KF marker，完整看：添加/删除/拖动素材、裁剪、分割、ripple、snapping、轨道排序、多选、框选、playhead。**重点：操作组合**（拖素材+播放头+KF 这种单功能测不出的组合）。

### ⑤ 播放器 Player（提前）
- play/pause/seek/frame stepping/audio sync/video sync/buffering
- **三个时间有没有混**：`localUs` / `timelineUs` / `mediaUs`
- KF 强依赖：playhead time → media time → local time
- 播放器是否驱动编辑器状态（应该：播放器只被驱动）

### ⑥ 媒体 Media
文件解析/metadata/thumbnail/proxy/cache/async 加载——MP4 落轨、素材库消失的雷可能在这。

## 五、P2 模块详解

### ⑦ 数据模型（GPT：最大未知，必须深审）
逐字段比：Segment 模型（新版 clip/track/media/instance/transform/animation vs 我们 segment/params/animations）。
**数据模型错 → 后面所有功能"能跑但越来越补丁"**。

### ⑧ 命令/Undo
一次用户行为 = 一个 command = 一个 undo？100 次 mousemove 不能生成 100 次 undo（C3 已做，复核）。

### ⑨ 导出 Export
静态导出/KF 导出/坐标转换/fps/duration/effects/audio。

### ⑩ MCP / AI 接口
**保留并强化**（我们的优势）：Command API 可表达性（人拖一下 ↔ AI "move clip A to x=300 at 5s"）、操作日志/Event Sourcing。
