## P0（用户点名 + 真 bug，明天先做）

### 1. 标尺：两级刻度（OpenCut 标尺 vs 我们"一格一格"）⭐ 用户点名
**OpenCut 源码**：`timeline/components/timeline-ruler.tsx` + `timeline/ruler-utils.ts` + `timeline/components/timeline-tick.tsx`
**差距**：
- 我们：单一刻度带标签（rulerStep 1/2/5/10s），"一格一格"
- OpenCut：**两级刻度** —— 主刻度 label（MIN_LABEL_SPACING_PX=120 保证可读）+ 细分 tick（MIN_TICK_SPACING_PX=18）
- OpenCut 间隔自适应：**帧级** 1/2/3/5/10/15 → **秒级** 1/2/3/5/10/15/30/60/120/300/600/900/1800/3600（LABEL_FRAME_INTERVALS + SECOND_MULTIPLIERS 表）
- OpenCut label 格式：秒边界 `00:00`（formatTimestamp），帧内 `3f`（formatRulerLabel）
- OpenCut 虚拟化：只渲染可视区 tick（startTickIndex~endTickIndex）+ buffer

**实施**：timeline.js 重写 rulerStep/rulerLabel 为两级（labelInterval + tickInterval）+ 虚拟化渲染。工作量 ~1h。

### 2. trim 补素材手感（用户实测 bug）
**现状**：截两段后往前拉，应补回被裁掉的素材（左拉回到 src_start=0，右拉回到素材尾）。后端 `trim_segment` 支持，前端手感未接对。
**实施**：排查前端 trim 拖拽到后端的参数传递 + 边界限制。工作量 ~0.5h。
