## 0. 怎么跑起来（每次验收前必做）
1. 关掉正在跑的 `start.bat`（若开着）。

## 1. M2 真机验收（Command 闭环 / undo-redo / 事务 / 乐观锁 / version 门控）

### 1.1 【你独立】undo/redo 模型（2c）
- **操作**：连续做 ~50 次小编辑（移动片段、改属性、加字幕、加书签…）→ 一路狂点 Undo 退到开头 → 再 Redo 回来。
- **看什么**：每步 Undo 是否精确回退**一步**；Redo 是否逐位恢复。
- **达标**：退到第 1 步与最初草稿逐位一致；Redo 后状态完全回来。
- **不达标**：Undo 一次跳多步 / 吞掉某次编辑 / Redo 状态错位。

### 1.2 【需我配合】乐观锁 + 双进程并发（2e，R1）
- **操作**：我开 MCP 写命令改某段，你同时桌面编辑**同一段**。
- **看什么**：是否出现**冲突码提示**，而非静默覆盖。
- **达标**：冲突码可见、两进程改动都不丢。
- **不达标**：一方改动被无声覆盖（严重 bug）。

### 1.3 【需我配合】事务超时 / 长事务（2d，R6）
- **操作**：我造一个"事务内卡住 >30s"的场景（如批量导入中途挂起），看是否误 abort。
- **看什么**：长事务是否自动续期、不误 abort；批量中途失败是否整体回滚。
- **达标**：不误 abort；失败整体回滚。
- **不达标**：30s 一到把正常长事务 abort 了。

### 1.4 【需我配合】version 门控（2f）
- **操作**：我把轮询间隔从 500ms 放宽到 2000ms，你正常编辑。
- **看什么**：体感是否零变化（门控保证只有真实变化才拉全量）。
- **达标**：放宽后完全无感知差异。
- **不达标**：放宽后界面不刷新 / 卡顿。

### 1.5 【需我配合】audit_log 落盘（2a）
- **操作**：我查 `audit_log.jsonl` 是否每条含 `args`，且**重启 start.bat 后文件仍在**。
- **看什么**：审计记录持久化、不随进程退出丢失。
- **达标**：含 args、重启不丢。
- **不达标**：重启后审计为空 / 无 args（护城河只在单进程存活期内）。

## 2. M4 真机验收（事件驱动 / 渲染切片 / 不卡死）

### 2.1 【需我配合】MCP 写入桌面 <100ms 可见（4a）
- **操作**：我经 MCP 改一段属性，你看桌面是否 100ms 内刷新。
- **看什么**：桌面是否即时反映 MCP 改动。
- **达标**：<100ms 可见。
- **不达标**：桌面要等轮询才更新（>秒级）。

### 2.2 【你独立】拖拽 5 分钟不卡死（4d，RefreshGate）
- **操作**：连续拖片段、调关键帧、缩放**5 分钟**。
- **看什么**：是否出现"点不动 / 卡死 / 必须刷新才恢复"。
- **达标**：全程流畅。
- **不达标**：卡死 → 查 `_suppressPanelRender` 与三层锁是否真删干净（M4 验收①）。

### 2.3 【你独立】切 slice 后面板核对（4b）
- **操作**：切到不同渲染切片（如只订阅时间轴 / 只订阅属性面板），逐项核对面板更新。
- **看什么**：切片切换后面板数据是否各自正确。
- **达标**：逐面板对齐。
- **不达标**：切 slice 后某面板数据 stale。

### 2.4 【需我配合】轮询 10s 无感知（4a / 2f）
- **操作**：我把轮询放到 10s，你正常操作。
- **看什么**：体感是否有差异。
- **达标**：无任何可感知差异（事件驱动已接管）。
- **不达标**：10s 轮询下明显卡顿 / 不刷新。

### 3.2 【你独立】5b 属性读写 = 导出（面板改位置/缩放 → 导出剪映一致）
- **操作**：选中片段 → 属性面板改 `x / y / 缩放 / 旋转 / 透明度` → 导出剪映草稿 → 剪映里看位置缩放。
- **看什么**：剪映里位置/缩放/旋转/透明度是否与面板一致。
- **达标**：完全一致（params 已成唯一真相源）。
- **不达标**：漂移 → 说明 params 没真成真相源（R9 回归）。

### 3.3 【你独立】5b 变速 / 音量 预览 = 导出
- **操作**：改 `speed` / 音量 → 预览听 → 导出剪映 → 剪映里听。
- **看什么**：速度、音调、音量是否一致。
- **达标**：一致。
- **不达标**：预览和导出对不上。

### 3.4 【你独立】5b 旧草稿属性不丢
- **操作**：加载一个**含 params 层的旧草稿** → 看属性是否都在。
- **看什么**：旧草稿的属性读写 + 导出是否与 M4 前一致。
- **达标**：不丢、导出一致（LEGACY_READ 兜底生效）。
- **不达标**：旧草稿属性丢失 / 导出漂移。

### 3.5 【你独立】5c 特效参数动画预览正常
- **操作**：加特效 → 给特效参数打关键帧 → 预览看动画。
- **看什么**：特效参数是否随关键帧动画。
- **达标**：动画正常（统一 `animations["effect.{param}"]` 通道生效）。
- **不达标**：特效参数不动 / 动画错乱。

### 3.6 【你独立】5c 导出剪映诚实降级（关键预期！）
- **操作**：带特效导出剪映 → 看导出日志 / 控制台是否记 `skipped`。
- **看什么**：是否出现"特效为预览专用滤镜（剪映草稿不支持 CSS 滤镜），已跳过导出"。
- **达标**：记进 `skipped` 提示（不静默丢）。
- **⚠️ 注意**：**特效不进剪映是预期，不是 bug** —— 剪映原生特效体系与咱们的 CSS 滤镜不是一套，立项时就知道烤不进去。MP4 线（未建）才是烤特效的地方。
- **不达标**：特效被静默丢弃、无任何提示（违反诚实降级）。

### 3.7 【你独立】5c 旧草稿特效 keyframes 兜底
- **操作**：加载旧草稿（含旧扁平 `keyframes` 特效）→ 预览看特效动画是否还在。
- **看什么**：旧特效是否仍能动。
- **达标**：旧特效仍动（legacy 扁平 keyframes 兜底生效）。
- **不达标**：旧草稿特效失效。
