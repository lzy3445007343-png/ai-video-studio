## 0. 怎么跑起来（每次验收前必做）
1. 关掉正在跑的 `start.bat`（若开着）。
2. **双击 `start.bat` 重启**（改过 HTML/JS/PY 必须重启才生效，否则验的是旧代码）。
3. 工作台打开后：左侧素材库 → 导入 2-3 个素材（1 个视频 + 1 张图 + 1 段音频）→ 拖进时间轴。
4. **F12 打不开**（`debug=True` 已关，commit 801f989 清理）→ 想盯控制台日志，让我临时开或看后端窗口（start.bat 的黑窗口就是 Python 控制台，`[MIGRATE]`/`[SAVE-VERIFY-FAIL]` 等日志打在那）。

## 0.5 速通验证流（一次操作，多线验证）

> **原则**：下面每个场景一次操作同时验多条（共享同一操作场景）。**照场景走，不用照条目走**。每场景末尾标注覆盖的原条目号。
> **建议顺序**：独立场景 ①→⑦ 一口气做完（约 1 小时），然后喊我集中跑场景 ⑧。

### 场景 ① 开局：一次导入 + 一次重启 → 同时验 3 条
- **操作**：导入 2-3 个素材（视频/图/音频）拖进时间轴 → 重启 `start.bat`（若手头有旧草稿，用旧草稿启动一次）。
- **同时验**：
  - M1-1.6：重启后看后端控制台 `[SCHEMA]` 日志（旧文件补版本号）
  - M3-3.1：旧草稿启动看 `[MIGRATE]` 日志 + 数据零丢失
  - M2-2.5：查 `audit_log.jsonl` 文件在（重启后审计持久化，含 args）
- **顺带**：备好素材，后面所有场景直接用它。

### 场景 ② 编辑+撤销循环：一次 50 步编辑 → 同时验 4 条
- **操作**：连续编辑（**移动片段 + 改属性 + 变速 + 加字幕 + 加书签**混着来 ~50 步）→ 一路 Undo 退到开头 → Redo 回来。
- **同时验**：
  - M2-2.1：undo/redo 逐位精确 + **重点：连续 ≥2 步后 Ctrl+Z 不弹"外部已改动"**（撤销死循环修复点）
  - M1-1.3：编辑里含变速 → 变速后音画对位、时长正确
  - M3-3.4：编辑过程中保存 → 后端无 `[SAVE-VERIFY-FAIL]`
  - M3-3.2：编辑全程流畅 → 无 ffprobe 反复探测阻塞

### 场景 ③ 删素材：接②的草稿 → 1 条
- **操作**：素材库删一个已拖进时间轴的素材。
- **同时验**：M1-1.1 时间轴段保留 + **硬盘文件不删**。

### 场景 ④ 拖拽压力：一次 5 分钟 → 同时验 2-3 条
- **操作**：连续拖片段 / 调关键帧 / 缩放 5 分钟 → 拖完撤销几步。
- **同时验**：
  - M4-4.2 全程不卡死（RefreshGate 生效）
  - M2-2.1 拖拽后 undo 正常（复用②的撤销验证）
  - ⚠️ **留意**：拖素材时是否触发"时间轴+素材库清空"老 bug（B12 类）——复现就记录，这是遗留项

### 场景 ⑤ 导出对拍：一次导出 → 同时验 3-4 条
- **操作**：改属性/变速/**加特效**后导出剪映草稿 → 剪映里打开看。
- **同时验**：
  - M5-5.6 导出日志/控制台记 `skipped`（特效不进剪映是预期）
  - M5-5.2 属性=导出（⏸️ 参数面板未做齐可先标"待补验"）
  - M5-5.3 变速/音量=导出（⏸️ 同上）
  - M5-5.4 旧草稿属性不丢（若用旧草稿导出，LEGACY_READ 兜底）
- **顺带**：M5-5.5 特效参数动画（预览时看）可在这条线一起验。

### 场景 ⑥ 模板按钮：一次点击 → 1-2 条
- **操作**：右上角「**模板**」→ 弹窗应列 3 模板 → 点「基础文字排版」→ Ctrl+Z。
- **同时验**：M6-6.3 模板弹窗可见 + 一键排版 + **undo 一次整批回滚**。

### 场景 ⑦ 帧步进：一次操作 → 1 条
- **操作**：时间轴聚焦按方向键（←/→）→ 观察播放头；拖 KF 打点看吸附。

## 1. M1 真机验收（数据引用安全 / 变速统一 / 写失败可见 / schemaVersion 种子）

### 1.1 【你独立】删素材不误删文件（1a，R12）
- **操作**：素材库建 2 个素材 → 拖进时间轴（形成引用）→ 在素材库删其中一个素材。
- **看什么**：被删素材在时间轴上的段还在吗？源文件（硬盘上）还在吗？
- **达标**：时间轴段保留、**硬盘文件不删**（删除逻辑只清引用）。
- **不达标**：硬盘文件被删 → 严重 bug（R12 回归）。

### 1.2 【需我配合】seg_id 首选引用不漂（1b）
- **操作**：我经 MCP 用 `segid` 改一段属性 → 再把该段移到别的轨道 → 再改一次。
- **看什么**：两次操作是否都命中**同一个段**（不因轨位变化改错段）。
- **达标**：segid 引用稳定，重排轨后不漂。
- **不达标**：改了错段 → 引用漂移回归。

### 1.3 【你独立】变速音画对位（1c，R7）
- **操作**：对一段视频改 `speed=2`（选中段 → 速度面板/右键）→ 预览播放。
- **看什么**：画面与声音是否同步（口型/节拍对得上），变速后时长是否正确减半。
- **达标**：音画对位、时长正确（speed=2 → 时长/2）。
- **不达标**：音画脱节 → 变速换算未统一。

### 1.4 【你独立】写失败可见化（1d，R5）
- **操作**：把一个导出路径指到**只读目录**或**C 盘根目录**（无写权限）→ 触发一次保存/导出。
- **看什么**：界面是否明确报"写失败"，而不是假装成功。
- **达标**：返回 `{ok:false}` + 可见错误提示（不静默假成功）。
- **不达标**：界面说成功但磁盘没写入 → "假成功"回归。

### 1.5 【需我配合】MCP 读结构正确（1e）
- **操作**：我经 MCP 调 `list_tracks` / `get_track_text`。
- **看什么**：返回的轨道/文本是否与桌面界面一致。
- **达标**：读到正确数据（根目录读新结构生效）。
- **不达标**：读错/读旧 → MCP 通道与桌面不同源。

### 1.6 【你独立】schemaVersion 种子（1f）
- **操作**：找一个旧草稿（或把 `draft_state.json` 的 `schemaVersion` 改成 0/删掉）→ 重启 start.bat。
- **看什么**：后端控制台是否打 `[SCHEMA] from=0 to=1`（或 `[MIGRATE]`）日志；功能是否一切正常。
- **达标**：日志出现 + 功能零变化（旧文件被补上版本号）。
- **不达标**：报错/数据丢失 → 迁移器回归。

## 2. M2 真机验收（Command 闭环 / undo-redo / 事务 / 乐观锁 / version 门控）

### 2.1 【你独立】undo/redo 模型（2c）—— ✅ 已过（2026-08-24 你验过 1.1，50 步不卡；含撤销死循环修复 ad82b05）
- **操作**：连续做 ~50 次小编辑（移动片段、改属性、加字幕、加书签…）→ 一路 Undo 退到开头 → Redo 回来。
- **看什么**：每步精确回退一步；Redo 逐位恢复；**连续 ≥2 步后 Ctrl+Z 不弹"外部已改动"**（撤销死循环修复点）。
- **达标**：一路退到底不卡死、不弹冲突窗；Redo 全回来。
- **不达标**：第 2 次撤销起弹"外部已改动草稿"→ 2c-fix 回归。

### 2.2 【需我配合】乐观锁 + 双进程并发（2e，R1）
- **操作**：我开 MCP 改你正在编辑的**同一段**，你桌面同时改同一段。
- **看什么**：是否出现**冲突码提示**，而非静默覆盖。
- **达标**：冲突码可见、两进程改动都不丢。
- **不达标**：一方改动被无声覆盖（严重 bug）。

### 2.3 【需我配合】事务超时 / 长事务（2d，R6）
- **操作**：我造一个"事务内卡住 >30s"的场景（如批量导入中途挂起）。
- **看什么**：长事务是否自动续期、不误 abort；批量中途失败是否整体回滚。
- **达标**：不误 abort；失败整体回滚。
- **不达标**：30s 一到把正常长事务 abort 了。

### 2.4 【需我配合】version 门控（2f）
- **操作**：我把轮询间隔从 500ms 放宽到 2000ms，你正常编辑。
- **看什么**：体感是否零变化。
- **达标**：完全无感知差异。
- **不达标**：放宽后界面不刷新 / 卡顿。

### 2.5 【需我配合】audit_log 落盘（2a）
- **操作**：我做几步编辑 → 我查 `audit_log.jsonl` 是否每条含 `args` → 你重启 start.bat → 再查文件仍在。
- **看什么**：审计记录持久化、含 args、重启不丢。
- **达标**：含 args、重启不丢（护城河"谁改了什么"可复盘）。
- **不达标**：重启后审计为空 / 无 args。

## 3. M3 真机验收（迁移器 / 热路径 / 快照 / 读回验证）

### 3.1 【你独立】旧文件自动迁移零丢失（3a）

- **操作**：正常操作 2 分钟（拖动/改属性/切面板）。
- **看什么**：界面是否偶发卡顿；后端控制台是否反复刷 ffprobe 相关日志。
- **达标**：全程流畅、无 ffprobe 反复探测（热路径已清理）。
- **不达标**：卡顿 + ffprobe 刷屏 → 热路径回归。

### 3.3 【我看代码】路径级快照 + peaks 共享（3c）—— ✅ 白盒已验
- **操作**：我查 undo 栈快照是否走路径级（`_clone_draft_share_peaks`）而非整轨深拷贝。
- **达标**：快照共享 peaks 引用、路径级（内存优化生效）。
- **不达标**：仍整轨深拷贝（内存没降）。

### 3.4 【你独立】读回验证抽样化（3d）
- **操作**：正常编辑 + 保存若干次 → 看后端控制台是否出现 `[SAVE-VERIFY-FAIL]`。
- **看什么**：写盘是否稳定成功（无假成功）。
- **达标**：无 `[SAVE-VERIFY-FAIL]`；改啥存啥。
- **不达标**：出现 `[SAVE-VERIFY-FAIL]` → 写盘不一致。
